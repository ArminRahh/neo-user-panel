# Neo User Panel
**Professional WordPress User Panel by Neosys**

یک افزونه اختصاصی و سبک برای مدیریت پنل کاربری وردپرس که بر پایه شورت‌کد (Shortcode) طراحی شده و برای عملکرد بهینه، در پوشه `mu-plugins` قرار می‌گیرد.

## ویژگی‌ها
- **Lightweight:** بدون بار اضافی بر روی دیتابیس.
- **Shortcode-based:** قابلیت نمایش در هر برگه یا بخش از سایت.
- **MU-Plugin Ready:** اجرای خودکار و عدم امکان غیرفعال‌سازی توسط مدیران سایت (امنیت و پایداری بالا).
- **Custom Bootstrap:** دارای سیستم فعال‌ساز اختصاصی در فایل ایندکس.

## نصب و راه‌اندازی
از آنجایی که این یک **Must-Use Plugin** است، مراحل نصب به شرح زیر است:

1. وارد مسیر `wp-content/mu-plugins` در هاست خود شوید.
2. پوشه `neo-user-panel` را در این مسیر آپلود کنید.
3. فایل لودر (در صورت وجود) یا فایل اصلی را به ریشه `mu-plugins` منتقل کنید تا وردپرس آن را شناسایی کند.

## نحوه استفاده
برای نمایش پنل کاربری در هر کجای سایت، از شورت‌کد زیر استفاده کنید:
`[neo_user_panel]`
